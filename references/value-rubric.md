# 信息价值判据

这是为本 skill 设计的定性评估规则，不是经过统计验证的量表，不称为 SIFT 或其他机构的评分标准。

## 先声明比较对象

评估的是“这篇文章给特定读者带来什么”，不是事件重要性或作者知名度。

- 默认基线：本轮实际查到的既有报道/原始资料，一般读者。
- 用户给出行业、用途、已有知识时，调整基线；否则不假装知道其知识水平。
- 未系统检索历史资料，写“本次可查材料中”，不宣称首次、独家或全网没有。
- 时效区分“发表当时的合理性”和“当前使用价值”。旧文可有长期解释价值，突发新文也可能只有未核传闻。

## 分维度判断

| 维度 | 高价值的依据 | 降低价值或保留判断的情况 |
|---|---|---|
| 可信度（单独报告） | 关键事实有直接证据，必要时独立核验；承认限制 | 关键事实错、证据断链、截图不可溯源、主张超出材料 |
| 信息增量 | 新的一手事实、新数据、关键纠错，或可复核的新联系 | 同源重复、标题放大旧闻；新颖程度未查明则未知 |
| 解释贡献 | 揭示机制、边界、尺度或替代解释，让读者理解更准确 | 只换术语、用个案概括总体、把相关当因果 |
| 时效与适用性 | 日期/版本清楚，仍适合当前问题；或持久背景知识 | 已有修正却未注明、旧资料被包装成当前事实 |
| 相关性与判断用途 | 能减少与指定问题有关的不确定性，澄清选择或提出可查线索 | 与用途无关，或隐去关键条件让人更难判断 |
| 阅读成本与信息密度 | 重点、证据、限制易找到；阅读投入有实质回报 | 反复煽情、内容重复、读完只记住立场；长短本身不决定价值 |

未知维度标未知；不按零分处理。不要求文章必须提供行动方案，知识、解释与纠错本身有价值。

## 如何形成总判断

不默认计算总分，不将热度、新鲜度、可信度简单加权平均。

- **高**：有明确且有证据支撑的增量/解释/纠错贡献，对声明用途有帮助，核心缺陷不足以推翻贡献。
- **中**：事实有用但增量有限，或对入门读者有明显整理价值；局部缺口限制适用范围。
- **低**：几乎没有超出现成资料的贡献，或核心错误/误导使其不能支持文章声称的结论。指出仍可保留的局部事实。
- **待定**：正文不全、关键来源缺失、重大冲突未解，暂时无法判断贡献是否成立。

评级配一句“为什么”，及一个能改变评级的证据条件。不要将“待定”机械解释为中等。

关键事实未证实、潜在意义却大时：**事实价值待定，线索价值较高**。核心结论已被可靠证据推翻时：**作为事实依据价值低**；分析其传播话术的价值可另列，不能抵消造假。

## 典型校准

- 真实的重复新闻：可信度高，新增事实低；对新手可能有整理价值，专家可略过。
- 企业新闻稿：披露行为和可查指标有价值，广告动机不使其自动失真；未证实的效果承诺不能据此采信。
- 无新事实的好评论：以已核事实提出清楚机制和限制，解释价值可以高。
- 热门匿名爆料：热度无法弥补证据缺口；若关系重大且可追索，列为线索，不标高事实价值。
- 旧政策被当新政转发：原政策存在可证实，时间框架有误导；当前价值看现行版本与用户用途。
- 只拿到标题：只能评价标题所含主张与证据可得性，整篇信息价值待定。
- 原创但错误的文章：原创性不能补偿决定性事实错误。

## 用户明确要求分数时

可以给分维度粗粒度评分，并定义刻度、证据锚点、未知项和适用读者；说明是辅助比较的人工判断。缺少核心证据不出整体数值，不报虚假的精确置信概率。
