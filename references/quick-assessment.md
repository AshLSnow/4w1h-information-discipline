# 快速评估：给材料即可运行

## 输入与交付约定

输入可以是新闻链接、长文、公众号正文、公告、截图/PDF、或数篇围绕同一事件的文章。默认按一般读者评估“是否值得阅读、保留或继续查证”，不假定用户从事投资或已有特定知识。

默认交付约 500–900 中文字（必要的证据表和链接可超出），先给结论。用户要求极简时压缩，要求全面时展开。不要为凑字数隐藏决定性分歧。

## 第 1 轮：读原文并定位核验问题

1. 打开原始链接，读取能获取的正文及决定结论的图表/注释。记录标题、作者、发布/更新日期、事件日期、评估日期、文章类型及访问范围。
2. 访问受阻时，尝试作者主页、原始发布站或可访问的同文版本；版本一致性不明要说明。只取得片段时仅评估片段或可定位的具体主张，不给整篇定论。
3. 区分报道、评论、研究解读、预测、营销与讽刺；混合文章逐项分类。
4. 列出能改变文章结论的关键主张，通常 2–5 项，短文可更少。其余作为未逐项核验内容，不能声称全文事实全查。
5. 为每项设置核验问题：什么证据出现会支持它，什么会推翻/限制它？优先级按结论影响、错误后果和证据缺口决定。

主张类型：事实 / 推断 / 观点 / 预测 / 情绪修辞 / 行动诱导。事实优先找外部证据；观点审查事实前提与论证；预测记录期限、条件及可检验结果，未到期不能判为已发生。

## 第 2 轮：追溯与独立核验

根据第 1 轮识别的实体、数字、引文或事件制定搜索，而非只搜索标题。

- 追溯公告、论文、数据集、完整讲话、原视频、法规文本等原始材料。
- 查作者/机构身份及与主张相关的可验证利益关系。不要展开与主张无关的背景挖掘。
- 找能独立核实同一事实的材料，并主动搜更正、反例、限制条件、更新版本和替代解释。
- 核对数据分母、基准、样本、时间窗、单位，引用上下文与因果措辞。
- 判断首发与转载关系：A→B→C 的三篇报道是一个源头；同属一集团但各自取证也不能仅凭集团关系直接合并，需看实际依据。
- 一手资料不必然无偏。机构新闻稿能证明其发布了某数字；数字的测量可靠性需看方法和其他证据。

搜索结果摘要只用于定位，决定性证据尽量打开原文。短引文、页码/章节或日期有助复核；不复制大段文章。

## 第 3 轮：针对分歧继续询证

第 2 轮后更新证据记录，将剩余问题具体化，继续查最可能改变价值结论的一项。

例：“营收增长 30%”原来是汇率调整后增长 → 下一轮寻找名义增长、统计期及可比口径，而不是继续搜增长 30% 的同文转载。

每轮留下简短可审计记录：待核问题 → 查到的来源与证据 → 主张状态变化/未变化 → 仍缺什么。无需展示所有搜索词或内部推演。

- 若有关键矛盾，检查是否由日期、地域、对象、定义、数据版本或研究设计差异造成。
- 有反对意见但无证据时，记录其限制，不把它当作推翻主张。
- 没有待解决分歧时，第 3 轮用于检验最强替代解释，以及文章相对原始材料是否真的增加信息。
- 实际只完成一轮就必须如实报告，不能写成已完成多轮。

## 核验预算与停止条件

默认以 3 个逻辑轮次组织，通常打开 4–8 份相关材料；这只是工作预算，不是可信度门槛，也不保证固定耗时。轮内独立查询可并行，下一轮须根据已获得的证据调整。

满足下列任一条件后收束：
- 决定结论的主张已有足够支持或明确反证，替代解释已检查，继续搜索难改变判断。
- 关键材料不可访问，合理替代路径亦无结果；交付受限结论及缺口。
- 连续两个针对性查询只带来同源重复，且没有新的可追索线索。
- 用户给定的时间/范围预算耗尽；交付已核范围，不降低证据门槛。

有明确新证据入口且可能改变结论，可针对性追加一轮。重大未解矛盾则给“有争议/待核”，不能为强行完成而裁定。用户要求深度核验时扩展范围；不默认无限搜索。

## 简短证据记录

工作中使用以下字段，可保留在上下文；默认不额外生成文件：

| 主张ID/类型 | 文章主张 | 来源及日期/定位 | 证据源头与独立性 | 支持/反证/限制 | 当前状态 |
|---|---|---|---|---|---|

状态可用：已证实、大体可信、部分成立、有误导性、错误、证据不足、无法核验。置信度附理由，不虚构百分比。只在确有支撑时使用“已证实”。

## 用 4W1H 解释后，再评估价值

将发现映射到五问，不机械填满所有格子。例如“为什么偏偏推给我”没有推荐日志和个人浏览记录时，就写无法确定。按 [价值判据](value-rubric.md) 评估文章本身的贡献，不能把 agent 搜索补充的事实记为文章的优点。

## 默认输出：信息价值卡

**结论：〔高 / 中 / 低 / 待定〕信息价值，〔适用读者/用途〕；〔精读 / 看摘要 / 只读原始资料 / 作为线索继续核验 / 可略过〕。** 一句话说明决定性原因。

- 可信度：核心事实状态；论证或预测单独说明。
- 增量与时效：相比什么基线增加了什么，现在是否仍适用。
- 最值得保留：1–3 条事实、解释或问题；注明文章提供还是外部核验补充。
- 关键核验：通常 2–4 行表，列“主张—核验结果—证据链接”，保留最重要反证/缺口。
- 4W1H 摘要：用短段落或一行五项交代信源、时间、目的证据、主张、行动诱导。已在证据表清楚体现的信息不重复。
- 使用边界：哪些可以采信、哪些仅作观点/线索；需要什么证据才改变判断。
- 核验范围：全文/节选、主要核验项、实际轮次、截至日期及重大访问限制。

不要把“值得关注”写成持续跟踪承诺，不要将阅读价值直接翻译成买卖、停药等行为建议。没有足够材料时“待定”是有效输出。
